# CreateX Diagrams

Technical diagrams and visual documentation for the CreateX smart contract system.

## Diagram Types

- **Architecture** - System overview and component relationships
- **Contract Flow** - Smart contract interaction sequences
- **Deployment** - CREATE/CREATE2/CREATE3 deployment flows
- **Security** - Security model and threat analysis visuals

## Tools Used

- Mermaid diagrams (for markdown integration)
- Draw.io/Lucidchart exports
- PlantUML diagrams
- Custom illustrations

## File Formats

- `.svg` - Vector diagrams (preferred)
- `.png` - Raster exports for documentation
- `.mmd` - Mermaid source files
