# CreateX Icons

This directory contains UI icons and symbolic graphics for the CreateX project.

## Categories

- **Navigation** - Menu, arrow, and navigation icons
- **Actions** - Button icons, CTA elements
- **Status** - Success, error, warning, info indicators
- **Features** - Icons representing specific CreateX features
- **Blockchain** - Ethereum, contract, deployment related icons

## Format Guidelines

- Primary format: SVG for scalability
- Size variants: 16px, 24px, 32px, 48px
- Style: Consistent with CreateX visual identity
